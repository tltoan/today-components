The user explicitly approved the following policy set in the native implementation chat. This supersedes earlier unresolved-policy statements in this library. | Topic | Approved behavior |
| --- | --- |
| Creation | Existing habit detail menu → sharing consent → Book cover invitation → system share sheet. Preserve onboarding. |
| Authority and invitations | Creator controls invites, member removal and shared weekdays. Revocable links expire in seven days and admit people only while seats remain; maximum four including creator. |
| Timezone and schedule | Fixed creator IANA timezone. Weekday changes begin the next party-local day, retaining past schedules. |
| Joining/resuming | Share only new entries. Eligibility for the streak begins the next scheduled party day. No same-day obligation. |
| Pause/trial end | Exclude the member from the current open date onward; preserve closed-day membership. Trials/reflections remain personal, with no automatic continuation. |
| Leave/removal | End access and further sharing immediately. Previously shared posts remain for the remaining members. |
| Account deletion and succession | Remove that author's shared content. Longest-standing active member succeeds a departing/deleted creator; an empty party closes. Retained roster evidence is anonymous. |
| Backdating and correction | Share backdated entries only for eligible dates after joining; reject writes received after leave/removal. Corrections/deletions recalculate party progress; the private Home streak stays frozen. |

Recipient flow: invitation → sign in if needed → personal target/unit → explicit Join → the existing habit detail's Party view. Link creation, system sharing and acceptance are distinct events. No automatic contact upload or message sending. This policy does not approve nudges or full Workshop compositions. Shared media retention/blocking details must be consistent with these rules.
